# 历史水墨立绘

## 固定规格

- 使用 `gpt-image-2` 生成新立绘。
- 将生成画布和交付文件固定为 **672×1008 像素**、竖版、严格 **2:3**。这是同时满足两边为 16 的倍数、总像素不少于 655,360 的最小 2:3 合法尺寸：`672×1008 = 677,376`。
- 输出 PNG，RGB/RGBA 均可；不得带文字、题签、印章、水印、边框或透明缺口。
- 人物采用膝上或大腿中部以上构图，头部和冠帽完整，主体边缘清楚，缩略到 300×450 时仍可辨认。

## 权威输入

按以下顺序读取，冲突时以前者为准：

1. 当前 Mod 根目录 `AGENTS.md`。
2. `Prompts/mod-brief.json` 的国家与 `characterBrief`。
3. 对应配置行的姓名、简介、年龄、类型、官职、国家和社会阶层。
4. `Prompts/world.md`、`Data_Country.json` 及同国其他人物，用于时代和阵营上下文。
5. 可靠历史资料，只补充服制、器物、地域和公开史实，不覆盖 Mod 的架空设定。

不得仅凭文件名猜人物。生成前为每个人建立简短角色卡：时代、国家、年龄、身份、性格、一个历史或设定典故、服装体系、专属道具、专属背景、主色与禁用元素。

## 统一美术方向

- 开始生图前必须查看 `assets/style-reference-zongze.png`。它是本 skill 的基准样张，只用于约束低饱和彩墨、宣纸明度、淡墨线条、笔触洁净度、人物细节清晰度与背景虚实层次。
- 将基准样张作为 image generation 的 reference image 输入；不得复用其人物面貌、红袍、幞头、扶案姿势、黄河渡口、汴京城墙、地图或刀剑构图。每名新人物仍须使用自己的角色锚点重新构图。
- 使用低饱和彩色水墨：暖象牙宣纸底、淡墨勾线、克制水墨晕染，以灰朱红、石青、灰玉绿、哑藤黄和暖灰点色。
- 保持画面干净整洁：皮肤、衣纹、甲片、冠饰和建筑轮廓清晰；留白有控制，不让墨迹吞没五官和手部。
- 禁止毛刺、锯齿、胶片颗粒、纸屑、随机墨点、脏污、破边、过度泼墨、AI 噪点、过锐化、高饱和、霓虹色、现代摄影感和写实 3D 渲染。
- 可从参考图提取色彩、媒介、笔触洁净度和虚实层次等高层特征；不得复刻参考图的构图、人物姿态、纹样、旗帜或其他可识别元素。
- 服装、盔甲、发式、冠帽和器物必须符合人物所属时代与文化，避免混用明清服装、日式甲胄、现代奇幻盔甲或影视影楼造型。

## 差异化设计

每张图至少确定四个不可互换的角色锚点：

1. **面貌锚点**：年龄、脸型、须发、风霜程度、神情。
2. **身份锚点**：文武、品级、族群、宫廷或地方身份对应的服饰。
3. **典故锚点**：与人物公开史实或 Mod 简介直接相关的道具、动作或环境线索。
4. **地域锚点**：江南、河北、河西、草原、绿洲、西南山地等可辨认环境。

同一批次不得连续复用相同的正面站姿、手势、帽冠、背景建筑、主色和光线。文臣不统一拿笏板，武将不统一握刀，后宫人物不统一置于宫苑。背景应叙事化但保持次要，不抢人物面部。

## 提示词结构

每个人单独生成，不用一个通用提示词批量换名。提示词依次写：

1. 用途与精确尺寸；
2. 人物身份、年龄和时代；
3. 面貌、服饰、姿态；
4. 历史或设定典故；
5. 专属背景与地域；
6. 统一水墨风格；
7. 构图和缩略图可读性；
8. 禁止项。

必须包含：`no text, no calligraphy, no seal, no watermark, no border, clean edges, no random ink splatter, no grain, no noise`。

## 文件与配置闭环

- 官员/武将：保存到 `Art/Portraits/OfficialAvatar/<CountryID>/<稳定名称>.png`；将 `Data_DefaultOfficials.json` 同一行的 `DefaultPortrait` 写为不含扩展名的 `<稳定名称>`。
- 默认后宫：保存到 `Art/Portraits/ConcubineAvatar/<CountryID>/<稳定名称>.png`；将 `Data_DefaultConcubines.json` 同一行的 `DefaultPortrait` 写为不含扩展名的 `<稳定名称>`。若通用后宫池另有 `portraitPath`，同时按真实表契约核对，不得猜字段格式。
- 国家/君主：保存到 `Art/Portraits/CountryPortraits/<稳定名称>.png`；将 `Data_Country.json` 的 `MonarchPortrait` 写为 `CountryPortraits/<稳定名称>`。
- 文件名不得含路径分隔符或文件系统保留字符。同名人物跨国冲突时附加国家或稳定 ID，不改人物显示名。
- 替换前备份将被覆盖的现有文件和 JSON；不得删除原模板或地图资源。

## 单张验收

每张图落盘前后都检查：

- 像素严格为 672×1008，比例为 2:3，PNG 可解码。
- 人物身份、年龄、性别、服饰与典故吻合，且与同批其他人物明显不同。
- 五官、双手、冠帽、武器和服装结构自然，无多指、断肢、融合器物或乱码。
- 无噪点、脏边、文字、水印、印章和不必要装饰框。
- 文件存在于正确 CountryID 目录，配置值不含扩展名且能唯一映射到文件。
- JSON 保持表格结构并可完整解析；不改变 `row_number`、稳定 ID 或无关字段。

先完成一张“配置读取 → 角色卡 → 生图 → 视觉检查 → 文件落盘 → 配置更新 → 路径复核”的最小闭环。只有玩家确认样张风格后，才批量生成剩余人物。
